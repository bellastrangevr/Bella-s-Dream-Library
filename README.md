# Bella's Dream Library

The published dreams for **Bella's Dream Library**, a VRChat world where dreams shared by the community become books on the shelves.

`dreams.json` is updated automatically when a new dream is approved, and the world reads it from
https://bellastrangevr.github.io/Bella-s-Dream-Library/dreams.json

Want your dream in the library? Visit the world and press **Submit a Dream**.
